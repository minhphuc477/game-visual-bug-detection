# Converted Markdown Papers

This directory stores full-text Markdown versions of research papers converted using **Microsoft MarkItDown** (`scripts/convert_papers.py`).

## Features
- Preserves clean headings, tables, formulas, citations, and structure.
- Injects standard YAML front-matter with title, author, year, SHA-256 hash, and conversion metadata.
- Enables lightning-fast full-text search, grep, LLM indexing, and RAG across your literature collection.
- Master index is automatically compiled in `markdown/INDEX.md`.
